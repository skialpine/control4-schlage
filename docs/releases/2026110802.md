# Property publication lifecycle — 2026110802-beta.1

This is a **prerelease for testing**. Stable/Latest remains **v2026110608**.

## Changes

- Publish startup Properties from OnDriverLateInit in both drivers, following
  the documented DriverWorks API timing requirement.
- Cancel the account's old work during OnDriverInit without publishing property
  or variable values from cleanup callbacks. Keep variable registration and
  binding restoration in Init.
- Initialize display values before restoring the session and starting discovery,
  so startup defaults cannot overwrite fresh results.

This corrects initialization timing. The user reported that Properties stayed
correct after this update. That is one successful live observation, not proof
that every Composer cache issue is resolved. The driver does not force a
Composer refresh through an undocumented API. Schlage authentication, lock
commands, bindings, and notification policy are unchanged.

## Upgrade and live check

Select **Schlage Account → Update Channel → Prerelease**, then run **Actions →
Check for Updates**. Both driver versions should become **2026110802**.

Leave Composer open during this test update. Check that discovery/polling values
refresh and that the generic Door Lock still controls and reports the selected
physical lock. If Properties remain stale, try **File → Refresh** before
restarting Composer. That command is documented to refresh the project, but its
effect on this specific issue remains unverified. Restarting Composer corrected
the stale display on 2026110801.

For manual installation, import/synchronize through Composer. Delivery files use
the main OneDrive Control4 folder; the Drivers directory is not written.

## Validation scope

Source regressions passed: **58 Lua suites / 2,546 assertions** and **53 Python
tests**. New lifecycle checks count early property/list/value API calls,
including cleanup paths; exercise fresh and live reinitialization; verify old
requests are cancelled, old responses cannot publish, saved-session discovery
resumes, and companion reinitialization does not fabricate movement events.

Eight suites also passed against the packaged scripts with source imports
excluded, totaling **500 assertions**. Formatting/static checks, strict OpenSpec
validation, and the local build passed. Both packages declare version
2026110802\.

Independent review of all changes is required before every commit. The user
reported correct post-update Properties; Lock/Unlock and app-state feedback
acceptance on this version remain pending. Outage/recovery testing and scheduled
daily battery follow-up remain deferred or unverified as previously recorded.
