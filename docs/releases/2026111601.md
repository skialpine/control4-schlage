# 2026111601 — Template maintenance

This prerelease updates the shared template from v0.9.103 to v0.9.109. It fixes
how documentation lists are formatted around conditional sections and adds a
build check to catch uneven spacing.

Lock control and status handling are the same as 2026111401. This release also
includes that version's startup recovery improvements, sorted Composer lock
conditions, and credential masking at Ultra.

Each physical lock continues to use its own Schlage Lock companion, configured
with the existing account and lock dropdowns. Saved credentials, selected locks,
and Navigator connections are kept.

## Updating

Select **Update Channel → Prerelease** in Schlage Account, then run **Actions →
Check for Updates**. Both drivers should show **2026111601** afterward. For a
manual update, import both `.c4z` files through Composer. Let Composer manage
its Drivers folder.

If Composer shows old values, use **File → Refresh** or restart Composer and
reconnect. Synchronize the driver definition through **Manage Drivers** if
settings are missing.

## Testing

Automated checks cover account sign-in, discovery, lock commands, status,
battery alerts, reloads, and credential masking. This version still needs
controller testing. Check saved sign-in, selected locks, lock/unlock, app status,
the Log Level dropdown, and both Documentation tabs after updating.

**2026110802 remains the stable release.** Outage recovery and scheduled daily
low-battery reminders still need hardware testing.
