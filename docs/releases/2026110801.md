# Template maintenance — 2026110801

Updates the Schlage Account and Schlage Lock drivers from Finite Labs template
v0.9.74 to **v0.9.80**.

## Changes

- Fixes shared connection binding logic when renaming connections that share
  peers with other connections.
- Uses smaller bitn/crypto bundles with development self-tests and benchmarks
  removed. Runtime native crypto checks are retained.
- Includes optional HTTP size/header/redirect controls, variable/property
  separation, and improved shared regression fixtures.
- Keeps structured Ultra logging while explicitly disabling raw HTTP, handler,
  timer, and websocket dumps after logger settings are applied. Existing
  credential filtering remains in place.

This update preserves Schlage authentication, polling, lock commands,
notifications, and update settings. It adds no OAuth, expression engine,
external diagnostics service, or local/offline control.

## Upgrade

Run **Schlage Account → Actions → Check for Updates** on either Stable or
Prerelease. Both driver versions should become **2026110801**. Saved credentials,
physical-lock selections, and generic Door Lock bindings remain in place.

Manual downloads include both `.c4z` files and the bundle with documentation
PDFs. Import or synchronize through Composer; do not externally overwrite
Composer's Drivers directory. OneDrive deliveries use the main Control4 folder.

## Validation

Source regressions passed: **58 Lua suites / 2,521 assertions** and **53 Python
tests**, including Cognito/SRP, connection binding, command scheduling,
notifications, and account/companion logging confidentiality. The initial
template-only test run caught the logger incompatibility; the driver adaptation
and added mode/level checks resolve it.

Eight suites also passed against the bundled scripts with source imports
excluded, totaling **475 assertions**. All 73 rendered shared library/vendor/test
files match a fresh v0.9.80 render exactly. Format/static checks, strict OpenSpec
validation, and the local build passed; both package versions are 2026110801.

Previously recorded hardware coverage is CORE1 / OS 3.4.3 and CORE5 / OS 4.3 with
two Encode Plus BE499WB locks. This maintenance has no new controller acceptance
result. Outage/recovery remains deferred at the user's request, and scheduled
daily battery follow-up checks remain unverified on hardware.
