# 2026111401 — Startup and programming improvements

This prerelease updates the shared driver template from v0.9.80 to v0.9.103.

- Improves startup recovery when saved connection or programming entries are
  incomplete. Existing valid programming IDs are kept.
- Sorts the lock's conditions in Composer so they are easier to find.
- Updates logging and build tools while keeping credentials masked, including
  at Ultra.

No new setup is required. Saved credentials, selected locks, and Navigator
connections are kept.

## Updating

Select **Update Channel → Prerelease** in Schlage Account, then run **Actions →
Check for Updates**. Both drivers should show **2026111401** afterward. For a
manual update, import both `.c4z` files through Composer. Let Composer manage
its Drivers folder.

If Composer shows old values, use **File → Refresh** or restart Composer and
reconnect. Synchronize the driver definition through **Manage Drivers** if
settings are missing.

## Testing

Automated sign-in, discovery, lock control, status, battery alert, reload, and
credential-masking tests pass. This version still needs testing on a controller.
Please check saved sign-in, lock selection, lock/unlock, app status updates, and
the Log Level dropdown after updating.

**2026110802 remains the stable release.** Outage recovery and scheduled daily
low-battery reminders still need hardware testing.
